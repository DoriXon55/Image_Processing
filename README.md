# Image Processing - Laboratory 

## Description
This repository contains implementations of various image processing techniques using OpenCV library. The project was developed as part of university laboratory coursework in Image Processing.

## Technologies
- Java (91.6%)
- Python (8.4%)
- OpenCV

## Features
- Basic image operations (loading, saving, displaying)
- Image transformations (scaling, rotation, translation)
- Image filtering (median filter, Gaussian filter, etc.)
- Morphological operations
- Edge detection
- Image segmentation
- Histogram analysis
- Image object detection

## Requirements
- Java JDK
- Python 3.x
- OpenCV
- Required libraries and dependencies

## Installation and Running
1. Clone the repository
2. Install required dependencies
3. Compile and run the project according to documentation instructions

## Laboratory Tasks
This project includes implementations of various image processing tasks:
- Lab 1: Basic image operations and manipulations
- Lab 2: Image filtering and noise reduction
- Lab 3: Edge detection algorithms
- Lab 4: Image segmentation techniques
- Lab 5: Histogram operations
- Lab 6: Morphological operations
- Lab 7: Advanced image processing techniques
- Lab 8: Car detection
- Lab 9: Fire detection from thermal camera

## Note
This project was created as part of the Image Processing laboratory course curriculum.
